# ro-epg

Rumänischer Sendeplan (XMLTV) für Smart IPTV, zweimal täglich automatisch aktualisiert.

- Quelle: epgshare01 (`epg_ripper_RO1.xml.gz`)
- Kennungen: Smart-IPTV-Codes (siptv.app/codes, Romania)
- Dizi hat die eigene Kennung `TimelessDizi.ro`, weil Smart IPTV für `Dizi.ro` keine Daten liefert.

EPG-Adresse für siptv.app/mylist: `https://raw.githubusercontent.com/<benutzer>/ro-epg/main/epg.xml`

Manuell aktualisieren: Actions → „EPG aktualisieren“ → „Run workflow“.
